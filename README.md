# fenbi-tool-tampermonkey

# 一个简单的粉笔题库解析复盘增强的油猴脚本

这是一款油猴脚本，用于粉笔网解析页面的功能增强。

## 功能
- 自动为每道题添加评论区
- 专项练习按每5题统计用时
- 试卷模式按模块统计用时
- 直观查看单体用时
- 自定义范围用时统计，如手动指定计算3-10题的总用时

## 安装
1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击下方链接直接安装：
   [安装脚本](https://raw.githubusercontent.com/Czream/fenbi-tool-tampermonkey/main/fenbi-tool.user.js)
3. 或者打开本仓库中的 `fenbi-tool.user.js` 文件，点击 “Raw” 按钮。
